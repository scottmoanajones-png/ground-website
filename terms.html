1. Description of the Platform

The Platform is a non-custodial infrastructure that provides an API platform used to access on-chain yield sources for financial platforms and applications. The Platform provides clients with access to a service that enables the creation and management of portfolio wallets for the purpose of allocating USDC to a selection of supported yield-generating strategies. USDC and receipt tokens are held in portfolio wallets using Turnkey MPC.

Smart contract services are used to facilitate and route USDC to the clients' selected yield sources and enforce whitelisted destination constraints. Clients may select more than one yield source, and direct the Platform to rebalance portfolio wallets if the allocations deviate from the client's previously specified allocation percentages. The Platform further provides access, through API and user interface, to real-time information regarding portfolio wallet balances, yield, and transaction activity, along with webhooks and activity logs.

While Ground has admin control and is the creator of the Platform, Ground does not and cannot take custody of digital assets which you trade or send utilizing the tools available on the Platform. All assets are held in a non-custodial system provided by Turnkey MPC with 2/2 signing.
